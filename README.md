# ngon-chords · 正 X 边形弦图

拖动滑块，看圆内接正 n 边形从 3 条边一路长到 100 条边，并且每个顶点都和其余所有顶点连成弦。

n = 4 是正方形加两条对角线，n = 5 直接出五角星，n 大了就是一张密到发光的曼陀罗／花窗。
所有弦合起来就是完全图 Kₙ。

## 打开

双击 `polygon.html`，或拖进浏览器。单文件、零依赖，不用构建、不用联网。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 拖动滑块 | 3 ~ 100 边形，实时重绘 |
| ▶ 播放 | 每 50ms 加一条边，到 100 后绕回 3，一轮约 5 秒；再点一下暂停 |
| 标题栏 | 显示当前边数和弦总数 N(N-1)/2（最多 4950 条） |

## 实现

- 一个 HTML 文件，Canvas 2D 手画，没有框架和构建步骤。
- 顶点坐标按固定外接圆半径算一次，所有弦攒进同一条 path，一次 `stroke()` 提交。
- 边数越多线越密，弦的透明度按 `20/N` 自动递减，外轮廓恒定 2px 亮色压边。
- 高清屏按 `devicePixelRatio` 放大后备缓冲，几何坐标恒定在 600×600 的**逻辑**画布内 —— 这两者混用会把图形放大到只剩一角。
- 自动播放用 `requestAnimationFrame` + 时间累计推进：`setInterval` 的触发时机跟着主线程抖动，跟屏幕刷新率不同步，看起来就是一顿一顿的。
